WHAT IT CHECKS

Common URL red flags

  • Unencrypted HTTP connections
  • IP addresses used as website hosts
  • Lookalike internationalised domain labels
  • Embedded username or password fields
  • Unusual ports and long hostnames
WHAT IT DOES NOT DO

No false promises

  • It does not visit or download the site.
  • It does not query threat-intelligence databases.
  • It cannot confirm ownership or reputation.
  • It cannot guarantee a link is harmless.
  • It never sends your input to an API.
